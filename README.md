# Laravel Memo App

Laravelで作成したシンプルなメモ管理アプリです。

メモの登録、一覧表示、編集、削除、検索、ページネーションに対応しています。  
Laravelの基本的なMVC構成やCRUD処理を学習するために作成しました。

---

## 使用技術

- PHP
- Laravel 12
- MySQL
- Blade
- HTML
- CSS
- XAMPP
- VS Code

---

## 機能一覧

- メモ一覧表示
- メモ新規登録
- メモ編集
- メモ削除
- 削除前の確認ダイアログ
- バリデーション
- 日本語エラーメッセージ
- 成功メッセージ表示
- キーワード検索
- 検索リセット
- 検索結果0件表示
- 検索中キーワード表示
- 作成日時表示
- ページネーション
- 件数表示

---

## 画面構成

- `/`：トップページ
- `/memos`：メモ一覧画面
- `/memo/form`：メモ登録画面
- `/memo/{id}/edit`：メモ編集画面
